Active Flight Control Rocket

An ESP32-based active flight control system for high-power rocketry, combining PID-controlled fin actuators, Simulink-based flight dynamics modeling, and custom embedded avionics to achieve stable controlled flight.

MATLAB / Simulink ESP32 (C/C++) Fusion 360 PID Control IMU / GPS / Altimeter High-Power Rocketry

Overview

An active flight control system for high-power rocketry, built to address the stability failure observed in the IREC rocket project. The system uses an ESP32-based flight computer with a PID controller driving fin actuators to actively correct the vehicle's flight path in real time.

This project is a direct continuation of the IREC rocket work. The previous launch attempt revealed that passive fin geometry alone was insufficient to maintain stable vertical flight under the actual launch conditions. This project aims to replace passive stability with an active control system capable of correcting attitude in real time. The controller is designed in Simulink, the fin actuator mechanism in Fusion 360, and the embedded implementation runs on an ESP32 flight computer. A test launch is planned to validate the system under real flight conditions.

Problem & Approach

The IREC rocket project demonstrated that a passively stable rocket can still fail to maintain stable flight if late-stage mass changes shift the CG/CP relationship or if environmental conditions are not accounted for in the simulation. Passive fin geometry provides no correction once the vehicle begins to deviate from its intended flight path.

The approach for this project is to add an active control layer: a PID controller reads attitude data from an IMU, computes the correction needed, and drives servo-actuated fins to apply that correction in real time. The full flight dynamics model is developed in Simulink before any hardware is built, allowing the PID gains to be tuned in simulation and verified before embedded implementation.

System Architecture

The system is organized around three layers: sensing, control, and actuation. The IMU and barometric altimeter provide state feedback to the ESP32 flight computer. The PID controller running on the ESP32 computes correction commands and drives the fin actuators through servo PWM signals. GPS provides position data for recovery and post-flight analysis.

Software Stack

Design Tools

  • MATLAB / Simulink: 6DOF flight dynamics model, PID controller design, gain tuning, and hardware-in-loop validation.
  • Fusion 360: Fin actuator mechanism design, servo mount, and airframe mounts.
  • OpenRocket: Initial CG/CP verification before Simulink modeling.

Embedded ESP32

  • Language: C/C++ using the Arduino framework.
  • IDE: PlatformIO.
  • Libraries: MPU6050, Adafruit BMP3XX, TinyGPS++, ESP32Servo, and SD.

Control Loop

  • IMU sampled at 500Hz.
  • Kalman filter for attitude estimation.
  • PID controller computes fin deflection commands.
  • Servo PWM updated at each loop iteration.
  • Altimeter and GPS sampled at 10Hz.

Ground / Post-Flight

  • Python and MATLAB for SD card log parsing and flight data visualization.
  • PID performance analysis from logged data.

Limitations

This project is currently in progress. All claims at this stage are limited to design intent and simulation results. No flight validation has been completed yet. PID gains tuned in Simulink may require further adjustment after real hardware testing, as simulation models cannot fully capture all aerodynamic and structural dynamics of the actual vehicle.
