# Who Kang — Aerospace Engineering Portfolio

This repository hosts my personal engineering portfolio website through GitHub Pages.

I am an Aeronautics & Astronautics student at the University of Washington with an FAA Airframe & Powerplant certificate. My portfolio focuses on hands-on aerospace hardware, UAV systems, flight controls, high-power rocketry, robotics, composite manufacturing, and engineering analysis.

## Live Site

https://khoy2k.github.io/

## Portfolio Direction

The site is organized around evidence-based project pages. Each project emphasizes the engineering problem, my contribution, technical artifacts, outcomes, limitations, and lessons learned rather than only final results.

## Featured Projects

- **Active Flight Control Rocket** — ESP32-based PID flight control system for high-power rocketry with active fin actuators, Simulink modeling, and a planned test launch.
- **Multimodal UAV Control via Voice and SSVEP** — UAV command verification testbed integrating voice recognition, SSVEP classification, ESP32 routing, Betaflight configuration, and latency/accuracy validation.
- **ML-Based Defect Detection for Automated Fiber Placement** — UW G3MS Lab research support in AFP defect documentation, composite prepreg workflows, microscope imaging, and additive manufacturing trials.
- **Autonomous Patrol Robot Systems Analysis** — K-Capstone feasibility study using survey processing, stakeholder criteria, Python/Pandas analysis, and a weighted Robot Feasibility Index.
- **IREC-Oriented High-Power Rocket Fabrication** — OpenRocket stability analysis, dual-deploy architecture review, composite airframe fabrication, and launch-attempt documentation.
- **AIAA DBF-Style Aircraft Design & Build** — Student-led aircraft design work covering aerodynamic sizing, CAD, rib-and-spar wing structure, and early-stage build planning.
- **NAR Level 1 Rocketry Certification** — High-power rocket preparation, launch readiness, stability awareness, and recovery system execution.
